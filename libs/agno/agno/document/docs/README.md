# Document模块文档

本目录包含了Agno框架Document模块的详细文档，使用Markdown格式和Mermaid流程图来说明其功能和工作流程。

## 文档目录

1. [Document模块概述](document_overview.md) - Document模块的总体介绍和主要组件
2. [Document类详解](document_class.md) - Document类的结构和功能详解
3. [Reader系统详解](reader_system.md) - 文档读取系统的结构和工作流程
4. [Chunking系统详解](chunking_system.md) - 文档分块系统的结构和工作流程
5. [文档嵌入过程详解](embedding_process.md) - 文档嵌入的过程和应用
6. [完整工作流程](complete_workflow.md) - Document模块的完整工作流程示例

## 如何阅读这些文档

建议按照以下顺序阅读这些文档：

1. 首先阅读[Document模块概述](document_overview.md)，了解整个模块的结构和功能
2. 然后阅读[Document类详解](document_class.md)，了解核心数据结构
3. 接着阅读[Reader系统详解](reader_system.md)和[Chunking系统详解](chunking_system.md)，了解文档处理的两个主要步骤
4. 然后阅读[文档嵌入过程详解](embedding_process.md)，了解如何将文档转换为向量表示
5. 最后阅读[完整工作流程](complete_workflow.md)，了解如何将这些组件组合起来使用

## 查看流程图

这些文档中包含了多个使用Mermaid语法编写的流程图，可以通过以下方式查看：

1. 使用支持Mermaid的Markdown查看器（如GitHub、GitLab、VS Code等）
2. 使用在线Mermaid编辑器：[Mermaid Live Editor](https://mermaid.live/)
3. 使用Mermaid CLI工具将流程图转换为图片
